# CYB3801_CTF

## Area targeted for CTF creation:
Create a web challenge where a modified API call has to be made with BurpSuite to return the flag, which then has to be decoded with CyberChef.

## Tools needed to create CTF challenge:
- BurpSuite
- Python
- CyberChef

## Idea planned and execution plans:
- Have a web form that takes an input and makes an api call to return a value once the submit button is clicked.
- The person doing the challenge will have to guess the correct call to make to get an encoded flag back.
- The person doing the challenge will then have to decode the flag with CyberChef.
